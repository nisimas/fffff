FUNCTION LAB — обновлённая версия

Состав:
- FUNCTION_LAB_fixed.html — обновлённый сайт; STL-модель уже встроена в HTML.
- functions/api/kui.js — защищённая серверная функция текстового помощника.

Что изменено:
- Точки навигации теперь находятся справа по центру экрана. Исправлено наследование глобальных стилей nav: left:0 и растягивание панели на всю ширину.
- Из окна помощника удалены названия и упоминания сторонних моделей.
- Удалены голосовой ввод, кнопка «Говорить», переключатель голоса и озвучивание ответов. Остался текстовый ввод.
- Серверная функция использует официальный DeepSeek Chat Completions API и модель deepseek-flash.
- Ключ не встроен в файлы: он должен храниться только в серверном секрете DEEPSEEK_API_KEY.

Развёртывание Cloudflare Pages:
1. Разместите FUNCTION_LAB_fixed.html как index.html.
2. Добавьте functions/api/kui.js в папку functions/api проекта.
3. В Settings → Variables and Secrets добавьте secret DEEPSEEK_API_KEY.
4. Вставьте туда новый ключ и выполните redeploy.

ВАЖНО: ключ, отправленный в чате, раскрыт в сообщении. Отзовите его в панели DeepSeek и создайте новый. Новый ключ вводите только в серверный secret, не в HTML/JS/репозиторий.

Документация: https://api-docs.deepseek.com/api/create-chat-completion/
